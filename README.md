# Overall survival in advanced lung cancer: Kaplan-Meier and Cox regression in R

Survival analysis of the NCCTG advanced lung cancer data (`lung` dataset, R `survival` package), written as a short statistical analysis plan followed by a fully reproducible report.

## What this project covers

- A statistical analysis plan (objective, endpoint, definitions, methods, missing data handling) written before the analysis
- Descriptive statistics and median follow-up (reverse Kaplan-Meier)
- Kaplan-Meier estimates of overall survival, overall and by sex, with median OS and 95% confidence intervals
- Log-rank test between men and women
- Univariable and multivariable Cox proportional hazards models (sex, age, ECOG performance status), with a forest plot
- Proportional hazards assumption checked with scaled Schoenfeld residuals (`cox.zph`)
- Discussion of limitations (small sample, complete-case analysis, no multiplicity adjustment)

## How to run

Install the packages once:

```r
install.packages(c("survival", "dplyr", "ggplot2", "broom", "rmarkdown", "knitr"))
```

Then render the report:

```r
rmarkdown::render("survival_lung_analysis.Rmd")
```

No data file is needed: the dataset is included in the `survival` package.
